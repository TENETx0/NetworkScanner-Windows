# 🛡️ Simple Windows Network Scanner by Tenetx01

A powerful C#-based Windows Forms application for deep network scanning, port mapping, cryptographic analysis, IoT detection, and more — wrapped in a modern GUI for professional use.

---

## 🚀 Features

- 🔍 **Enhanced Basic Scan**: TTL-based OS detection, HTTP fingerprinting, vendor resolution from MAC, full port sweep.
- 📡 **Advanced Enumeration**: SMB, SNMP, NetBIOS, RDP, spoofable protocol checks, and SQL/hosting fingerprinting.
- 🤖 **IoT Device Detection**: Port & banner-based smart device fingerprinting.
- 🔐 **Cryptographic Metadata Analysis**: SSL cert inspection, expiration alerts, and strength ratings.
- 🌐 **VPN/Proxy Detection**: ASN range checks, reverse DNS analysis, known VPN port scan.
- 📂 **File Sharing Port Scan**: Detects high-risk ports like SMB, AFP, NFS with risk scoring.
- 🔀 **Port to Application Mapper**: 300+ port-to-service mapping including LAMP/MEAN/MERN stack.
- 📄 **HTML Report Export**: One-click stylish report generation with syntax-safe formatting.

## 🧑‍💻 Usage Instructions

1. 🔧 **Download the MSI/.exe File to install The application on windows**:
   - Install the application on windows
   - Windows OS

2. 📥 **Input Format**:
   - Single IP: `192.168.1.5`
   - IP Range: `192.168.1.1-192.168.1.10`

3. ✅ **Running a Scan**:
   - Enter valid IP/range in the textbox.
   - Select one or more checkboxes for the desired scan modules.
   - Click **Scan** to begin.

4. 💾 **Export Report**:
   - Click **Save** to export an HTML version of the scan log.

5. 🔗 **About**:
   - Link label redirects to https://github.com/TENETx0/NetworkScanner-Windows/wiki for deeper learning.
     
6. 🗑️ **Uninstall**:
   - You'll find "Installer NetworkScanner" in your Programs,By uninstalling You can uninstall the application completely from the System
